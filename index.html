Интеграция с Wildberries Advert API

Загрузка расходов на рекламу по SKU

Подключите API-токен Wildberries с категорией «Продвижение / Реклама». Сервис автоматически запросит списания на рекламу за период отчета и разнесет затраты по каждому артикулу для точного расчета чистой прибыли.

Добавить новый API токен

Токены хранятся исключительно в вашем браузере (LocalStorage) и никогда не передаются на сторонние серверы.

Как получить токен в кабинете Wildberries:
  1. Откройте Личный кабинет WB Партнеры.
  2. Перейдите в Профиль (Настройки) → Доступ к API.
  3. Нажмите «Создать новый токен».
  4. Выберите категорию «Продвижение» (или «Реклама»).
  5. Скопируйте ключ и вставьте в форму выше.
