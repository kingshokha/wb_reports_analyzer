# Правила проекта WB Finance Analytics

## 1. Правила Git-коммитов и версий
- Сообщения коммитов пишутся строго на русском языке.
- В конце каждого сообщения коммита ОБЯЗАТЕЛЬНО указывается версия проекта (пример: `git commit -m "Описание изменений v1.9.4"`).
- Бейдж версии в правом верхнем углу `index.html` обновляется при каждом изменении с указанием текущей даты: `vX.Y.Z | DD.MM.YYYY`.

## 2. Стандарты построения графиков (Chart.js)
- Все графики должны открываться мгновенно (`animation: false`).
- Линии графика делаются сплошными (`borderDash: []`) с круглыми точками (`pointStyle: 'circle'`).
- При использовании двух осей Y нули обеих осей строго выравниваются по одной горизонтальной линии (алгоритм синхронизации нулевой отметки - Вариант А).
- Значения `1` или малые величины не должны прилипать к нижней границе графика.
- На графиках динамики используется вертикальная пунктирная линия-линейка при наведении мыши (`verticalHoverLinePlugin`).
- Фильтрация «Скрыть нули» динамически учитывает только те показатели, которые активны в данный момент (отмечены галочками).

## 3. Хранение данных и сопоставление SKU
- Себестоимость, фулфилмент и реклама сохраняются и считываются по нормализованным ключам (`trim()`, `parseInt`, `supplierSku`, регистронезависимый поиск).
- Формы не должны вызывать перезагрузку страницы (`type="button"` и `e.preventDefault()`).
