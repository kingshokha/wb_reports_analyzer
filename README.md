# WB Finance Analytics & Report Merger

Анализатор финансовых отчетов Wildberries и инструмент объединения нескольких отчетов. Работает полностью локально в браузере.

---

## 📁 Архитектура и структура файлов проекта

Проект построен по модульной структуре для чистоты кода и максимальной скорости разработки.

```
/
├── index.html               # Основная HTML-разметка, каркас интерфейса и подключение скриптов
├── README.md                # Документация проекта и описание логики файлов
└── js/
    ├── core.js              # Базовые утилиты, состояние, карта колонок и localStorage
    ├── parser.js            # Парсинг Excel / CSV файлов и фильтрация по датам
    ├── tab_overview.js      # Логика вкладки «Сводная аналитика», графики и модальные окна
    ├── tab_products.js      # Логика вкладки «Анализ товаров по SKU», фильтры и экспорт
    ├── tab_cogs.js          # Логика вкладки «Себестоимость товаров», расчет и пагинация
    ├── cogs_io.js           # Импорт и экспорт себестоимости через буфер обмена
    ├── merger.js            # Инструмент «Объединитель отчетов WB» (сшивание файлов и ZIP)
    └── app.js               # Точка входа, переключение вкладок и обработчики событий
```

## 🧠 Описание логики каждого файла

### 1. `index.html`
- **Роль**: Главная точка входа веб-приложения.
- **Логика**:
  - Каркас SPA-интерфейса (Side-drawer для загрузки, экран приветствия, индикатор загрузки).
  - Разметка навигационных вкладок: *Сводная аналитика*, *Анализ товаров по SKU*, *Себестоимость товаров*.
  - Разметка всех карточек KPI, круговых диаграмм Chart.js, таблиц и фильтров.
  - Разметка всплывающих модальных окон (Детализация возвратов, Средняя СПП, Детализация удержаний, Детализация расходов WB, Объединитель отчетов, Импорт себестоимости).
  - Индикатор версии сайта и даты сборки в правом верхнем углу (`v1.3.0`).

### 2. `js/core.js`
- **Роль**: Фундамент приложения, глобальное состояние и базовые хелперы.
- **Логика**:
  - `COL_MAP`: Точное соответствие буквенных индексов колонок Excel (C=2, D=3, F=5, G=6, K=10, M=12, O=14, T=19, W=22, X=23, AC=28, AH=33, AK=36, AO=40, AP=41, AQ=42, BH=59, BI=60, BJ=61).
  - Функции перевода букв в индексы и обратно (`letterToIdx`, `idxToLetter`).
  - Форматирование данных: `formatCurrency` (рубли с копейками), `formatDate` (ДД.ММ.ГГГГ), `formatFileSize`, `parseNum`, `parseDate`, `toLocalInputDate`.
  - Парсинг CSV с поддержкой кодировок UTF-8 и Windows-1251 (`decodeText`, `parseCSV`, `splitCsvLine`).
  - Сохранение и загрузка себестоимости и фулфилмента в `localStorage` (`loadSkuCogsFromStorage`, `saveSkuCogsToStorage`).
  - Хранение глобального состояния `globalStats`, `productsList`, `filteredProducts`, `skuCogsMap`, `skuFfMap`.

### 3. `js/parser.js`
- **Роль**: Чтение и обработка финансовых отчетов Wildberries.
- **Логика**:
  - Обработка загрузки файлов через Drag & Drop и файловый проводник (`handleFile`).
  - Парсинг Excel-файлов (`.xlsx`, `.xls`) через SheetJS и `.csv` через встроенный парсер.
  - Автоматическое определение минимальной и максимальной даты операций по **столбцу M**.
  - Фильтрация строк по выбранному периоду (Все даты, Последние 30 дней, Предыдущие 30 дней, Произвольный период).
  - Накопление статистики продаж, возвратов, комиссий, эквайринга, логистики, штрафов, хранения, удержаний и приемки.
  - Управление выдвижной боковой панелью загрузки отчета (`toggleSidebarDrawer`, `closeSidebarDrawer`, `enableDrawerSidebar`).

### 4. `js/tab_overview.js`
- **Роль**: Расчет финансовой сводки и визуализация данных.
- **Логика**:
  - Расчет чистой прибыли по формуле:
    $$\text{Чистая прибыль} = \text{Выплата WB (AH)} - \text{Логистика (AK)} - \text{Хранение (BH)} - \text{Штрафы (AO)} - \text{Тарифы (AP)} - \text{Удержания (BI)} - \text{Приемка (BJ)} - \text{Налог (O)} - \text{Реклама} - \text{Себестоимость} - \text{Прочее}$$
  - Отрисовка интерактивного графика динамики показателей по дням (`renderDailyTimelineChart`, `updateDailyTimelineChartVisibility`) с возможностью выбора отображаемых линий чекбоксами (Выкуп T, Чистая прибыль, К перечислению AH, Комиссия + эквайринг, Логистика AK, Возвраты T, Расходы WB, Удержания BI, Себестоимость COGS, Налог O) по дате транзакции (столбец M).
  - Отрисовка круговой диаграммы структуры финансов (`renderFinanceChart`).
  - Отрисовка детализации и диаграммы видов логистики (`renderLogisticsBreakdown`).
  - Управление модальными окнами:
    - `openReturnsModal` / `renderReturnsModalTable`: таблица всех возвратов с живым поиском.
    - `openSppModal` / `renderSppModalTable`: средняя СПП (%) с группировкой по категориям (столбец C).
    - `openTotalWbPayableModal`: сверка суммы к перечислению от WB.
    - `openExpensesModal`: детализация расходов WB.
    - `openDeductionsModal` / `sortDeductions` / `renderDeductionsTable`: детализация удержаний (BI) с сортировкой.

### 5. `js/tab_products.js`
- **Роль**: Анализ товаров по SKU.
- **Логика**:
  - Генерация и рендеринг таблицы товаров по артикулам (`renderProductTable`).
  - Расчет прибыли по каждому товару с вычитанием комиссии, эквайринга, логистики (AK), себестоимости и налога.
  - Строка итоговых сумм над таблицей (ИТОГО СУММЫ) со значком $\Sigma$.
  - Мульти-фильтр по категориям товаров (столбец C) с чекбоксами и бейджем количества (`toggleCategoryFilterDropdown`, `toggleCategory`, `toggleAllCategories`).
  - Фильтр видимости колонок таблицы (`toggleColumnFilterDropdown`, `toggleSkuColumn`, `toggleAllSkuColumns`).
  - Сортировка по всем полям таблицы (`sortProducts`).
  - Экспорт таблицы SKU в файл CSV (`exportSKUTableCSV`).

### 6. `js/tab_cogs.js`
- **Роль**: Управление себестоимостью товаров и фулфилментом.
- **Логика**:
  - Таблица ввода закупочной цены на 1 ед. и стоимости услуг фулфилмента на 1 ед. (`renderCogsTable`).
  - Живое обновление итоговой себестоимости при вводе значений (`updateSkuCogs`, `updateSkuFf`, `onCogsOrFfUpdated`).
  - Расчет суммарной себестоимости по всем проданным товарам (`calculateTotalCogs`).
  - Фильтр «Только без себестоимости» (`#chkOnlyNoCogs`).
  - Сортировка и пагинация по товарам.

### 7. `js/cogs_io.js`
- **Роль**: Импорт и экспорт себестоимости через буфер обмена.
- **Логика**:
  - `exportCogsToClipboard()`: копирует список всех артикулов с себестоимостью и фулфилментом в буфер обмена в формате:
    ```
    Артикул - закупка на 1 ед. - фулфилмент
    ```
    *Пример:* `201234567 - 350.00 - 45.00`
  - Всплывающие уведомления (Toast) об успешном копировании или ошибке (`showCogsToast`).
  - `openCogsImportModal()` / `closeCogsImportModal()`: управление модальным окном импорта.
  - `pasteFromClipboardToCogsImport()`: кнопка вставки текста напрямую из буфера обмена через `navigator.clipboard.readText()`.
  - `applyCogsImport()`: умный парсинг введенного текста (поддерживает разделители `-`, `—`, `\t` табуляцию из Excel, `;`, `,`), обновление `skuCogsMap` и `skuFfMap`, сохранение в `localStorage` и моментальный пересчет всей финансовой аналитики.

### 8. `js/merger.js`
- **Роль**: Объединитель еженедельных/ежемесячных отчетов Wildberries.
- **Логика**:
  - Загрузка множества файлов `.xlsx`, `.xls`, `.csv` или `.zip` архивов (`addFilesToMerger`).
  - Распаковка архивов ZIP на лету через JSZip.
  - Правило сшивания: **1-й отчет — основа с шапкой**, со всех последующих отчетов берутся строки со 2-й (без дублирования шапки).
  - Сборка и выгрузка итогового файла `.xlsx` через SheetJS (`exportMergedReport`).

### 9. `js/app.js`
- **Роль**: Инициализация и регистрация обработчиков событий.
- **Логика**:
  - `initEvents()`: переключение табов, Drag & Drop для главного отчета и объединителя, слушатели поиска, периода дат и кликов вне модальных окон для их закрытия.
  - `window.onload`: восстановление сохраненной себестоимости из `localStorage`, инициализация иконок Lucide Icons.

## 🔒 Безопасность и конфиденциальность

- Вся обработка финансовой информации происходит **исключительно на вашем компьютере (клиентский JavaScript)**.
- Никакие файлы отчетов, артикулы, цены и суммы **не отправляются на сервер**.
