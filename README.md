# WB Finance Analytics & Report Merger

Анализатор финансовых отчетов Wildberries и инструмент объединения нескольких отчетов.

## 🚀 Возможности

1. **Глубокая финансовая аналитика отчетов Wildberries**:
   - Чистый оборот, комиссии, эквайринг, налог 6%.
   - Удержания, штрафы (AO), логистика (AK), хранение (BH), приемка (BJ) и прочие расходы.
   - Детализация товаров по SKU (продано, возвраты, оборот, к выплате).
   - Учет себестоимости товаров (COGS) и дополнительных расходов (реклама, прочие издержки).
   - Наглядная структура расходов и диаграммы Chart.js.

2. **Объединитель отчетов (Excel / CSV / ZIP)**:
   - Объединяет несколько еженедельных или ежемесячных отчетов Wildberries в один итоговый `.xlsx` файл.
   - **Первый отчет считается основой** (сохраняет шапку/заголовок и все строки).
   - **Со второго и всех последующих отчетов** копируются все строки со 2-й строки (пропуская первую строку заголовка) и вставляются в конец отчета.
   - Поддерживает загрузку файлов списком или из `.zip` архивов.
   - Наглядный интерфейс модального окна со статусами каждого файла и функцией мгновенного экспорта.

3. **Конфиденциальность и безопасность**:
   - Вся обработка выполняется **100% локально** в браузере (Vanilla JS + SheetJS + JSZip).
   - Данные не передаются ни на какие сторонние сервера.

## 🛠 Технологии

- HTML5, Vanilla JavaScript
- Tailwind CSS
- Chart.js
- SheetJS (xlsx.full.min.js)
- JSZip
- Lucide Icons
